# PRODIGY_WD_04
Personal Portfolio Website:

This project is a responsive Personal Portfolio Website developed using HTML, CSS, and JavaScript. It is designed to showcase skills, projects, education, and contact information in a clean and visually appealing layout. The website provides a professional online presence and works smoothly across mobile, tablet, and desktop devices.

Features:

• Attractive home/landing section with introduction
• About Me section with background and education
• Skills section to highlight technical abilities
• Projects section to showcase work and achievements
• Contact section with social links or form
• Smooth navigation between sections
• Fully responsive design for all screen sizes
• Built using pure HTML, CSS, and JavaScript

Technologies Used:

• HTML5
• CSS3
• JavaScript

Project Objective:

The objective of this project is to create a professional portfolio website that helps present personal skills, projects, and achievements effectively while improving front-end web development skills.


How It Works:

The home section introduces the user with a headline and summary.
Navigation links allow users to move between sections like About, Skills, Projects, and Contact.
Projects are displayed with descriptions and visuals.
The contact section enables visitors to connect through email or social platforms.
JavaScript enhances interactivity and smooth scrolling.

Learning Outcomes:

• Designing modern and responsive web layouts
• Creating multi-section websites with navigation
• DOM manipulation and interactive UI development
• Organizing and presenting projects professionally
• Building a strong online developer presence
